1. If the game is broken go to src/wall_parent.py and uncomment the following lines to activate the full reset of the game: *44, 82, 94, 95*
and comment the lines of the normal reset: *98, 99*
then launch the game and click on the reset button to reset the inventory

2. If for any reason the server port doesn't work, you can change it at line *11* in src/network.py 

3. If you want to play on the internet you need to open your port and use TCP protocol

4. we recommend to play in fullscreen
